# 自製濾水器探究

一套適合國小五、六年級至國中七年級的互動式自然科學教材。學生以「原理—設計—測試—證據—改良」流程比較自製濾水器，並學會：水看起來清澈，不等於達到可安全飲用標準。

- 教材網站：https://prayer168.github.io/water-filter-inquiry-lab/
- 原始碼：https://github.com/prayer168/water-filter-inquiry-lab
- 版本：v1.1.2

## 學習目標

1. 解釋沉澱、篩濾與吸附的作用及能力邊界。
2. 比較石頭、礫石、粗砂、細砂、棉花、不織布、咖啡濾紙、海綿、木炭與活性碳。
3. 控制變因，以至少三次重複測試比較清澈度、流速、出水量、成本與操作難度。
4. 分開呈現觀察結果、科學證據與推論。
5. 不以外觀、氣味或自製濾柱結果判定飲用安全。

## 教材特色

- 8 個頁籤式學習站，主內容集中在單一任務面板。
- 沉澱、篩濾、活性碳吸附 SVG 階段動畫。
- 十種濾材比較器與完整特性表。
- 上／下行流向、厚度與配置預測模型。
- 自製清澈度尺、9 筆重複測量表與 CSV 下載。
- 6 則生活應用、10 題素養挑戰、進度與最佳分數保存。
- 6 筆中文、8 筆英文政府／大學／NASA／科學教育來源。
- 支援鍵盤、觸控、手機與 `prefers-reduced-motion`。

聚焦探究實作、工程設計、資料解釋、環境教育與安全教育。課綱代碼須由教師依正式課綱手冊與授課年級確認，本專案不杜撰代碼。

## 安全

自製濾水器只用於觀察物理過濾與吸附現象。實驗前後的水都不可飲用，也不可試喝。真正飲用水處理還需要適當消毒、操作管理與水質檢驗。
