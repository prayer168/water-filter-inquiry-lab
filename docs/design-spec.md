# 教材藍圖與設計規格

## 基本資料

- 中文教材名稱：自製濾水器探究
- 英文專案名稱：Water Filter Inquiry Lab
- Repository：`water-filter-inquiry-lab`（來源：英文教材名稱）
- 適用對象：國小五、六年級至國中七年級
- 領域：自然科學／工程設計
- 建議時間：兩節課，共 80–90 分鐘
- 模式：引導模式；保留教師版專業說明
- 視覺：參考《野外求生安全手冊》的深松綠、琥珀、紙張質感、編輯式大標與田野手冊氣氛；教材本體採頁籤式單一任務面板。

## 學習目標

1. 解釋沉澱、篩濾、深層過濾與吸附的差異。
2. 比較十種常見濾材的功能、限制、流速與成本。
3. 控制變因並以至少三次重複測試比較配置。
4. 分開記錄觀察、科學證據與推論。
5. 說明清澈水樣不等於可飲用水，遵守不試喝的安全規則。

## 先備知識

- 能量取液體體積與使用秒錶。
- 知道固體顆粒大小不同，水可流過材料間的孔隙。
- 知道公平比較時應一次只改變一項主要條件。

## 核心概念

- 顆粒先沉澱可降低濾床負荷。
- 礫石、砂與纖維材料主要透過孔隙與彎曲路徑攔截顆粒。
- 活性碳依多孔表面吸附特定分子，能力具選擇性且會飽和。
- 濾層越細或越厚，常提高顆粒截留機會但降低流速、增加堵塞風險。
- 正式飲用水處理還包含消毒、操作控制與檢驗。

## 頁籤架構

1. 任務基地：情境、目標、安全契約、完整流程鳥瞰。
2. 原理探索：沉澱、篩濾、吸附互動圖解。
3. 濾材圖鑑：十種濾材篩選、比較與特性表。
4. 配置實驗：拖曳／按鈕建立濾柱、流向切換、厚度與預測模型。
5. 證據紀錄：研究問題、變因、模擬污水配方、紀錄表與簡易濁度尺。
6. 生活應用：自來水廠、露營、魚缸、咖啡、雨水再利用、太空站等情境。
7. 闖關挑戰：10 題理解、應用、推理與資料判讀。
8. 自主學習：6 筆中文、8 筆英文權威資源與教師指引。

## 互動與動畫

- 三原理 SVG：逐步播放、暫停、重播，當前步驟與說明同步。
- 濾材比較器：依清澈度、流速、成本篩選與展開限制。
- 濾柱設計器：選擇 4 層、調整厚度、上／下行切換、即時比較預測。
- 清澈度尺：以滑桿模擬不同濁度，練習判讀圖樣可見度。
- 10 題測驗：即時回饋、解析、回看頁籤與重新挑戰。
- 學習進度：以 localStorage 保存已完成頁籤與最佳分數。

## 生活應用

六則情境均有專屬 Image 2.0 寫實圖片：自來水廠多重屏障、雨水園藝回用、咖啡沖煮、魚缸循環、露營用水與太空站回收。每則明確指出可借鑑原理與不可類推的限制；圖片不承擔精密標示或安全判定功能。

## 評量配置

- 理解：沉澱、篩濾、吸附與清澈度。
- 應用：活性碳預洗、安全聞氣味、出水速度取捨。
- 推理：控制變因、重複測試、一般木炭與活性碳差異。
- 現象判讀：清澈但未經消毒的水樣不可飲用。

## 課綱對應

聚焦探究實作、工程設計、資料解釋、環境與安全教育。正式課綱代碼待教師依授課年級與教育部手冊確認，不在無來源情況下自行填列。
